Exercise 5.6

1. Define a function called welcome_message that takes a string parameter name

and prints a message “Welcome, [name]!” When you call this function with

the argument “John,” it should print “Welcome, John!”

2. Write a function multiply_numbers that takes two parameters (both numbers)

and returns their product. Call this function with the numbers 4 and 5 and

print the result.

3. Create a function convert_to_uppercase that takes a string as input and returns the string in uppercase. Call this function with the input “python” and print the result.

4. Define a function average_of_numbers that takes a list of numbers as an

argument, calculates their average, and returns the average value. Test the

function with the list [5, 10, 15].

5. Write a function rectangle_area that accepts two parameters: length and width.

The function should return the area of the rectangle. Call the function with length = 6 units and width = 4units, and print the result.

Python lists

A list in Python is a collection that allows you to store multiple values in a single

variable. These values can be of any data type, such as numbers, strings, or even other

lists. Lists are very flexible and useful for managing and organising data.
