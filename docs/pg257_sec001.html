Creating a list

To create a list, you use square brackets [] and separate the items with commas.

For example: numbers = [1, 2, 3, 4, 5]

In this case, numbers are a list that contains the integers 1, 2, 3, 4, and 5.

Accessing list elements

You can access individual elements in a list by using their index. Python uses zero- based indexing, meaning the first element has an index of 0, the second has an index of 1, and so on.

For example:

lakes = ["Victoria", "Tanganyika", "Nyasa"] print(lakes[0]) # Output: Victoria print(lakes[1]) # Output: Tanganyika

In this example, lakes[0] gives the first item in the list, “Victoria.” Also, lakes[1] gives the second item, “Tanganyika.”

Modifying list elements

You can modify the elements in a list by accessing their index and assigning a new value to that index.

For example:

lakes = ["Victoria", "Tanganyika", "Nyasa"] print(lakes[0]) # Output: Victoria print(lakes[1]) # Output: Tanganyika

The second element (at index 1) in these codes was changed from “Tanganyika” to

“Natron.”
