To make a computer execute your program, you need a compiler. The importance of using a compiler includes:

(i) Translating source code into machine language – Computers cannot understand

English-like C code, so the compiler converts it into binary (machine code).

(ii) Checking for errors – The compiler detects and reports mistakes in your code, helping you correct them before running the program.

(iii) Creating an executable file – After compilation, the compiler generates a file that the computer can run directly.
