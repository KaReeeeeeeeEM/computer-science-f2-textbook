Activity 3.9:

Make a sprite move

1. Select a sprite by clicking a sprite button (or keep the default scratch cat).

2. Drag the “when green flag clicked” block from the “Events” section.

3. Attach the “move 10 steps” block from the “Motion” section.

4. Click the green flag to see the sprite move!
