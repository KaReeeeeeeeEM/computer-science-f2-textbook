Simple loop-based programs

You can use a for loop to generate a multiplication table for any number.

For example:

# Ask the user for a number num = int(input("Enter a number: "))

# Loop from 1 to 10 to generate the table

for i in range(1, 11):

print(f"{num} x {i} = {num * i}")

In the given code, the user inputs a number. The for loop repeats from 1 to 10,

multiplying the entered number by “” in each iteration and displaying the result.

for i in range(1, 11): print(f"5 x {i} = {5 * i}")
