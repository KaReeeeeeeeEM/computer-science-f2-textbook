Project 3: Shake and react game challenge

Aim: Create an interactive game that measures how quickly a player reacts after receiving a signal, using shaking as the trigger and clicking or input to measure response time.

Project Description: Design and create a simple “reaction game” in Scratch that

uses “Micro:bit as an input”. The game should challenge the player to react quickly

after a signal appears. The game starts when the player “shakes the Micro:bit”, and the player must respond as fast as possible.

Project requirements:

In your design include the following:

1. A “signal or visual alert” to tell the player when to react.

2. A way to “measure the reaction time” of the player.

3. Use of a “Micro:bit sensor” (such as, shake, tilt, or button) to begin the game.

4. Display the “reaction time result” at the end of each round.

5. A way to “restart or play again”.

Tools and Extensions: Use Scratch (web or offline); Add the Micro:bit extension;

You may simulate the Micro:bit or use a real device if available

Deliverables:

1. A complete Scratch project file or project link

2. A short written reflection (3–5 sentences) explaining:

(a) What was the most interesting part of building this game?

(b) What did you learn about sensors and Scratch?

(c) If you had more time, what would you add?
