Activity 1.6:

Understanding browser history and private mode

Aim: To help students explore how a

web browser stores browsing history

and understand the purpose and function

of private/incognito browsing mode.

Materials: A device with a web browser

(Computer, Tablet, or Smartphone);

Internet access (optional but useful)

and Exercise book or Digital portfolio.

Instructions:

1. Use your browser’s menu to find the

History section.

2. Look at the list of recently visited pages.

3. Close the browser and reopen it in

Private/Incognito Mode.

4. Visit any website and then check if it appears in the browser history.

Task:

1. Summarize the difference between

normal browsing and private

browsing in your own words.

2. List one reason why someone might

want to use private browsing mode.

Deliverable: Write a summary report

as per given task.
