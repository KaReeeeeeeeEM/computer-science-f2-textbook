Basic Internet related concepts

The Internet is a global network that

connects millions of computers, mobile

devices, and other digital systems. It enables communication, information sharing, and access to various online

services. To use the Internet effectively,

it is important to understand key terminologies related to its structure,

connectivity, and applications.

World Wide Web

A World Wide Web (WWW), sometimes

called the Web, is a system of interlinked

hypertext documents accessed via the

Internet. The documents are formatted

using a markup language called HTML

that supports links to other documents.

The HTML also supports graphics, audio,

and video files. The Web lets individuals,

organisations, and companies publish

information for other people to access.

Web page

A web page is a hypertext document that can be accessed over the WWW through web browsers. It is written in a markup language called HTML. It contains text, pictures, audio, video, and hyperlinks.

Website

A website is a collection of related web

pages with the same theme connected using hyperlinks. A Home page is the opening page of either a personal, commercial, or institutional website.
