Table 2.12: Types of threats in cloud computing

Challenge

Description

Data breaches

and loss

One of the biggest concerns in cloud computing is data breaches.

If cybercriminals access cloud storage, they can steal sensitive information, including personal details, financial records, and

business secrets. Data loss can also occur due to accidental

deletion, system failures, or cyberattacks like ransomware. To

prevent this, cloud providers use encryption and backup systems,

but users must also implement strong security measures like

multi-factor authentication.

Unauthorised access

Cloud services are accessible from anywhere, which increases the risk of unauthorised access. If a hacker steals a user’s login

credentials, they can misuse the cloud account and compromise

essential data. Weak passwords and a lack of access controls can

make systems more vulnerable. Organisations must use strong authentication methods and regularly monitor user activity to detect suspicious behaviour.

Insider threats

Not all security risks come from external hackers; sometimes, employees or authorised users can misuse cloud resources. A disgruntled employee or a careless user might accidentally leak

sensitive data or intentionally damage cloud systems. Companies

should enforce strict access controls, conduct regular security training, and monitor data usage to reduce insider threats.

Insecure APIs and interfaces

Cloud services rely on APIs (Application Programming

Interfaces) and web interfaces for communication. If these APIs

are not properly secured, attackers can exploit vulnerabilities

to gain control over cloud systems. Weak APIs can lead to

data leaks, unauthorised access, and other security breaches.

Cloud providers must ensure that APIs are well-protected with encryption, authentication, and regular updates.

Compliance and legal issues

Different countries have different laws regarding data privacy

and security. Businesses using cloud services must comply with

regulations such as GDPR (General Data Protection Regulation

by European union) and Tanzania comply to Personal Data

Protection Act. Failure to follow these laws can result in legal

penalties and loss of customer trust. Organisations should

carefully choose cloud providers that meet the required security

standards.
