Loops and iterations control flow in Python

Loops allow you to repeat a block of code multiple times. Python provides two main types of loops: for loops and while loops.

In Python, the for loop is used to iterate over a sequence (such as a list, string, or range). The loop starts with the for keyword, followed by a variable that holds each item in the sequence. A colon (:) marks the beginning of the loop block. The loop continues executing the block of code for each item in the sequence until all items

have been processed.

The for loop – Iterating over sequences

A for loop is used to iterate (go through) sequences like lists, strings, and rangesTo

better understand for loops, the range() function is introduced. This built-in function

generates a sequence of numbers, which is commonly used in for loops to define a

range of values to iterate over.

Syntax of range() function:

Range([start], stop[, step]), whereby

(i) start (optional): Specifies the beginning of the sequence. If not provided, it

defaults to 0.

(ii) stop (required): Specifies the end of the sequence. The sequence will generate

numbers up to (but not including) this value.

(iii) step (optional): Specifies the difference between consecutive numbers. It can

be positive or negative, but it cannot be zero.

fruits = ["umwembe", "chitoki", " fyulisi", "litowo"] for fruit in fruits: print(fruit)
