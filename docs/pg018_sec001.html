Web browser

A web browser is a software application used to access, retrieve, and view information

on the World Wide Web (WWW). It locates and retrieves information from a web

server and displays the retrieved content (such as text, images, or videos) on the user’s

computer or mobile screen. Web browsers are essential tools that allow users to visit websites, search for information, download content, and communicate online. The

Table 1.1 illustrates features of web browsers and Figure 1.6 indicates where they are located in the web browsers.

Table 1.1: Features of a web browser

Feature

Description

Address bar

A space where users can type a website address

(URL) or search terms.

Back and forward buttons

Allow users to move to previously visited pages or return to more recent ones.

Refresh or reload button

Reloads the current web page in case it did not load correctly or has been updated.

Tabs

Allow multiple websites to be opened and viewed

in one window simultaneously.

Bookmarks or favorites

Allow users to save websites for easy access in the future.

History

A list of previously visited web pages, which

users can revisit.

Download manager

Displays a list of files downloaded using the

browser.

Settings menu

Provides access to various browser options like privacy, appearance, and extensions.

Private or incognito mode

Allows browsing without saving history,

passwords, or cookies.
