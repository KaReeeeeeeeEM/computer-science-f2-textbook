Activity 1.13:

Creating a private e-mail account

Aim: To learn how to create a personal

email account using a free web-based

email service.

Materials: A computer, tablet, or

smartphone with Internet access, A

modern web browser (such as, Chrome,

Edge, Firefox), and a valid mobile

phone number (for verification)

Instructions: Use a computer, tablet, or

smartphone to create an e-mail account

for your personal use by following the

steps:

Step 1: Access an email service provider

(a) Open a web browser.

(b) In the address bar, type the web

address of an email service

provider such as Yahoo: www.

yahoo.com, Google (Gmail): www.gmail.com,

Outlook

(Hotmail): www.outlook.com

(c) If using Yahoo, click on the

'Mail' option on the homepage.

(d) On the Yahoo Mail page, click

'Create an account'.

Step 2: Fill out the registration form

(a) Enter your personal information, including:

(i) First name and surname

(ii) Gender (optional)

(iii) Date of birth

(iv) Country code and phone number

(b) Choose your desired email ID

(such as, yourname@yahoo.com).

•

If the ID is taken, select one

of the suggested alternatives

or try another.

(c) Create a strong password. Make sure it is easy to remember but hard for others to guess.

(d) Click 'Continue'.

Step 3: Verify your identity

(a) The Email service provider will send a verification code to your phone via SMS.
