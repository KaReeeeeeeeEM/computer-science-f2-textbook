Variables, data types, and constants are fundamental concepts in C programming that

help store and manipulate data efficiently.

Declaring and initializing variables

A variable is a name given to a space in the computer’s memory where a value is stored. A variable is like a labelled box in a computer’s memory that stores a value.

The type of the variable decides what kind of data it can hold, like numbers or letters.

In this case:

(a) Each variable has a name so we can find it easily.

(b) It has a size, meaning it takes up some space in memory.

(c) It has a lifetime, meaning it exists only while the program needs it.

(d) It has a scope, meaning it can only be used in certain parts of the program.

For example,

int age = 20; // A variable named "age" stores the number 20
