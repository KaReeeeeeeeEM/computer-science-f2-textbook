Increment (++) and decrement (--) operators

The increment (++) and decrement (--) operators increase or decrease a variable’s value by 1, respectively.

Increment operator (++)

The increment operator adds 1 to the variable’s value. The prefix (++a) increments

first and then uses the value, while the postfix (a++) uses the value first and then

increments.

Program examples:

(a) Prefix increment (++a)

int a = 15; int result = ++a; // a is incremented first (a = 16), then result = 16 printf("%d ", result);

Output: 16

(b) Postfix increment (a++) int a = 15;

int result=a++;//result = 15(value before increment),a is incremented after

printf("%d ", result);

Output: 15

Decrement operator (--)

The decrement operator subtracts 1 from the variable’s value. The prefix (--a)

decrements first and then uses the value, while the postfix (a--) uses the value first and then decrements.

Program examples:

(a) Decrement (--a)

int a = 15; int result = --a; // a is decremented first (a = 14), then result = 14 printf("%d ", result);

Output: 14

(b) Decrement (a--)

int a = 15;

int result=a--;//result=15(value before decrement),a is decremented after

printf("%d ", result);

Output: 15
