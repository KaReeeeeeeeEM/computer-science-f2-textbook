Activity 3.13:

Setting up Scratch for the reaction game

Aim: To create a reaction game and learn to set up variables, simulate delays, capture user input, calculate

reaction times, provide feedback, and

restart the game.

Materials: A computer or tablet with

Internet access to run Scratch; access

to Scratch via a web browser or the

Scratch desktop app; optional custom

sprites or backgrounds for the game;

and a timer, a built-in feature of Scratch

for measuring reaction time.

Instructions:

Step 1: Create a new project in

Scratch

(a) Open scratch and create a new

project.

(b) Delete the default scratch cat sprite

(you can upload your own if you’d

like).

Step 2: Define variables

(a) In the Blocks Palette, go to the

Variables section (orange colour).

(b) Click “Make a Variable” and create the following:

(i) Reaction time – to store the time the player takes to react.

(ii) Game start – to store the time when the game begins.

(iii) Choose “For all sprites”, then click OK.

Step 3: Create the game’s starting message

(a) From Events, drag: when the green

flag clicked

(b) From Looks, drag: “say [Wait for the green light to change!] for (2) seconds”

(c) From Control, drag: “wait (2) seconds”

Step 4: Simulate a random delay

(a) Add Random Wait:

(i) From Control, drag wait (1) seconds

(ii) Replace 1 with pick random 2 to 5

(Get pick random (1) to (10) from

Operators)

(b) Show “Green Light” Message:

From Looks, drag “say [Green

Light!] for (2) seconds”

Step 5: Get user input

(a) From Events, drag: “when [space v] key pressed”

(b) Calculate reaction time:

(i) From Variables, drag: set

[Reaction Time] to (0)

(ii) From Operators, drag ( ) - ( )

(iii) From Sensing, drag the timer into the first space

(iv) From Variables, drag Game Start into the second space

(v) Place the whole (timer - Game

Start) into the set Reaction Time block
