(a) Declaring a variable in C:

This means creating a variable and specifying its type.

For example,

int age; // This code declares an integer variable named ‘age’

Before using a variable in C, you must declare it. Variables can be declared in three places:

(i) Global variables (outside a function)

In this context, the variable is available throughout the entire program, meaning it

has a global scope. When a variable or function has global scope, three things apply:

First, it can be accessed from any part of the program. Second, it is declared outside

all functions, typically at the top of the code. Third, it remains in memory for the

duration of the program and does not disappear when a function ends. However,

using global declarations is generally discouraged, as they can lead to errors and

make debugging more difficult.

For example:

#include <stdio.h>

// Global variable (available throughout the program)

int number = 10;

void printNumber() {

printf("Number: %d\n", number); // Can access global variable

} int main() { printNumber(); // Output: Number: 10 number = 20; // Changing the global variable printNumber(); // Output: Number: 20 return 0;

}

OUTPUT:

Number: 10

Number: 20
