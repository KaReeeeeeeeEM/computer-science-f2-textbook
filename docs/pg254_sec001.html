Functions in Python

A function in Python is a block of code that performs a specific task. It is designed to take an input (called arguments), and return an output after performing a particular

operation. You can think of a function as a recipe. You provide the ingredients

(inputs), follow the recipe (function), and you get a dish (output).

Defining a function

To create a function in Python, we use the def keyword, followed by the function name, parentheses (for any input values), and a colon. The body of the function is indented (usually four (4) spaces).

For example:

def greet(): print("Hello, welcome to Africa!")

From this code, def is the keyword to define a function, greet() is the name of the function. The function performs a simple task: printing a greeting message.

Calling a function

Once a function is defined, you can use (or call) it by simply writing its name followed

by parentheses:

greet()

When you call the greet() function, it will print: Hello, welcome to Africa!

Functions with parameters (inputs)

A function can take inputs, which are values you provide when calling the function.

These inputs are called parameters or arguments.

For example:

def greet(name): print("Hello, " + name + "!")

Referring to this code, “name” is a parameter. The function will greet the person

whose name is passed as an argument.
