Authentication token

An authentication token is a small piece

of digital information used to verify a

user’s identity when accessing a website,

app, or online service. It acts like a digital

key that proves you are who you say you

are. When you log in with your username

and password, the system generates a

token and stores it securely. This token

is then used for future requests, so you

do not have to enter your password every

time. Authentication tokens help improve

security by reducing the risk of password

theft and making online access faster and

more convenient.

Biometric for authentication

Biometrics for authentication uses unique

physical or behavioral traits. Examples

include fingerprints, face recognition, and

voice patterns. These features help verify

a person’s identity. Instead of passwords

or PINs, biometric systems scan these

traits. This allows access to devices, apps,

or secure places. Everyone has unique

fingerprints and facial features. This

makes biometrics more secure and harder

to fake. Many smartphones and security

systems use biometrics. They are fast,

easy to use, and hard for hackers to steal.

Behavioural authentication

Behavioural authentication is a security method. It checks a user’s identity based

on how they behave when using devices.

This includes how they type, move a

mouse, or swipe a screen. These actions are unique to each person. They are hard for others to copy. The system watches these patterns. It can tell if the user is the right person. This adds security without needing extra passwords or devices.

Encryption authentication

Encryption keeps information safe by turning it into a secret code that only the right person can read. It is used to protect things like text messages, pass­ words, and personal information from hackers. Many apps and websites use encryption to keep your online activities private and secure.

For example, when you send a message, encryption makes sure only you and the

person you're chatting with can read it.
