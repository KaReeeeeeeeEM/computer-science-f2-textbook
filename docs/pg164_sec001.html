Writing and running a simple C program

Activity 4.4:

Writing and running a simple C

program

Aim: To write, compile, and execute a basic C program .

Materials: Computer with Windows,

macOS, or Linux; Installed C compiler

(GCC, MinGW, Clang, or Turbo C);

Text editor or IDE (Notepad++, VS

Code, Code::Blocks, or Dev-C++);

Command Prompt or Terminal for

compiling and running the program

Instructions:

Step 1: Write a simple C program

(a) Open a text editor like Notepad++,

VS Code, or Code::Blocks.

(b) Type the following code and save it as “habari.c”:

#include <stdio.h> int

"Habari, Africa!\n" return 0

Step 2: Compile the program

(a) Open Command Prompt (Windows) or Terminal (Linux/macOS).

(b) Navigate to the folder where your

file is saved using the cd command.

(c) Compile the program by typing:

gcc habari.c -o habari

Step 3: Run the program on Windows

habari.exe

Expected output:

Habari, Africa!
