Table 5.7: Built-in string methods

Method

Description

Example

upper()

Converts all characters

to uppercase

“hello”.upper() → “HELLO”

lower()

Converts all characters to lowercase

“Hello”.lower() → “hello”

replace (old, new)

Replaces part of a string with another

“apple”.replace(“a”, “A”) → “Apple”

split (separator)

Splits a string into a list

strip()

Removes whitespace from the beginning and end

find (substring)

Finds the position of a substring

“banana”.find(“na”) → 2

String formatting using f-strings

f-strings (formatted strings) allow easy and readable string formatting by embedding

variables directly inside {}.

(i) For example:

name = "Masantula" age = 25 print("My name is {name} and I am {age} years old.")

Output:

My name is Masantula, and I am 25 years old.

(ii) using calculations:

num1 = 20 num2 = 15 print(f"The sum of {num1} and {num2} is {num1 + num2}.”)

Output: The sum of 20 and 15 is 35.
