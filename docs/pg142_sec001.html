Activity 3.11:

Make a simple animation

1. Choose two or more costumes for your sprite.

(a) If your sprite has multiple

costumes, you will see them under

the “Costumes” tab.

Figure 3.15: Simple animation with costumes

(b) If not, click “Choose a Costume”

to add a new one.

2. Edit or add costumes – You can:

(a) Draw a new costume using the

Paint Editor.

(b) Upload an image from your

computer.

(c) Duplicate an existing costume

and make small changes (for

example, moving arms or legs

for a walking effect).

3. Use the “next costume” block inside

a “repeat” loop to create animation.

(a) Click on the “Code” tab to return to programming.

(b) Go to the “Looks” category

(purple blocks).

(c) Drag the “next costume” block into the coding area.

(d) Go to the “Control” category

(orange blocks) and drag a

“repeat 10” or “forever” block.

(e) Place the “next costume” block

inside the loop.

4. Add a “wait 0.5 seconds” block to slow it down.

(a) Go to the “Control” block again.

(b) Find the “wait 1 second” block and drag it inside the loop.

(c) Click on “1” and change it to

“0.5” (or a different value to

adjust speed).
