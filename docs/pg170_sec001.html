#include <stdio.h>

int main() {

// This code declares a variable to store the user’s name

char name[20];

// This code asks a user to type a name printf(“Enter your name: “);

// Get the user’s name using scanf scanf(“%s”, name);

// Greet the user

printf(“Hello, %s!\n”, name); // Use of newline escape sequence return 0;

}

Program example 4.1:

Structure and syntax of C program

Note that:

(a) The #include <stdio.h> directive adds the standard Input/Output library.

(b) The main() function serves as the starting point of the program.

(c) The printf() function prints output, while scanf() takes user input.

(d) // and /* */ are used to add comments explaining different parts of the code.

(e) The \n escape sequence shifts the output to a new line.
