Each NIC (Network Interface Card) has

a distinct MAC address, ensuring no conflicts during communication. The

MAC address and IP address work together to enable data transmission

between devices, with the hardware and

software collaborating to ensure accurate

delivery.

Activity 1.11:

Finding the MAC address on a Windows

machine

Aim: To locate the MAC address of the

network adapter (Ethernet or Wi-Fi) on a

Windows computer using the Command

Prompt.

Materials:A Windows computer,

Access to Command Prompt, Basic

knowledge of the computer’s network

adapter (Ethernet or Wi-Fi)

Instructions: Use a computer with

Windows Operating System to find the

MAC address by following the below

steps:

Step 1: Open the Start Menu and

type “cmd” to search for

Command Prompt.

Step 2: Click on Command Prompt

to open it.

Step 3: In the Command Prompt

window, type the command:

ipconfig/all,

then

press

Enter.

Hypertext Transfer Protocol

Hypertext Transfer Protocol (HTTP) is

a protocol that governs the process of transmitting information on the Web.

Additionally, it gives users a way to interact with web resources such as

HTML pages by transmitting hypertext

messages between clients and servers.

HTTP publishes and retrieves HTML pages on the World Wide Web. The information transferred using HTTP

can be plain text, audio, video, image,

or hypertext. The first part of the URL

contains the HTTP.

MAC address

Computers communicate with each

other through a part called the Network

Interface Card (NIC). Every computer

on a network needs a special, unique identity to be recognised easily. This

special identity is called a Media Access

Control (MAC) address. You can think

of a MAC address like a student’s school

ID number. Even if two students have the

same name, their school ID numbers are

always different and unique. Similarly,

even if two computers look the same

or are the same model, each one has a

different MAC address to identify it on the network.

The MAC address is a unique identifier assigned to each network adapter at the

time of manufacture. It consists of six

pairs of characters or digits (such as,

01:10:11:02:36:84), separated by colons.
