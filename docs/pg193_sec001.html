The C programming language offers

the following types of loops to manage repetitive execution:

(i) while loop: Continues executing a

statement or a group of statements as

long as a specified condition remains

true. The condition is evaluated

before entering the loop body.

(ii) for loop: Repeats a sequence of

statements multiple times while

simplifying the control of the loop variable within its structure.

(iii)Do…while loop: The do...while loop

functions similarly to the while loop

but evaluates the condition after

executing the loop body.

(a) while loop

In C programming, a “while” loop

continuously executes a specified

statement or block of statements as

long as the given condition remains true.

Syntax:

while (condition) { statement(s);

}

Referring to this syntax above, the

condition can be any expression, and it is considered true if it is evaluated as a

nonzero value. The statement(s) can be a

single statement or a group of statements

enclosed in {}. The loop continues to run

while the condition evaluates to true.

Once the condition is evaluated as false,

the control moves to the first statement

after the loop. A flow diagram for the
