Materials: Computers or laptops with

installed code editors (Such as, VS Code,

Code::Blocks, PyCharm, Notepad++);

Pre-installed programming languages

(at least C, Python, JavaScript, C++,

Java; A worksheet or notebook to record findings; Internet access (for

documentation and syntax reference);

Sample starter code or templates

(optional).

Instructions:

Step 1: Perform comparison features

of

two

programming

languages based on: Syntax

simplicity, Type declaration,

Variable initialization, Object-

oriented support, Memory

management, Compiled or

interpreted, Error handling,

Use of curly braces, Use of

semicolons, Popular use cases

Step 2: Investigate two programming

languages (Such as , Python

vs C, JavaScript vs Java, C++

vs Python). Then,

(a) Write simple code snippets in

both languages (such as, print

a message, declare a variable,

handle an error).

(b) Research or test features like

whether the language requires

semicolons, how memory is

managed, whether curly braces are used, etc.

Step 3: Fill in a comparison table

in a worksheet or notebook,

based on experimentation or

research

Step 4: For each language, write a basic program such as a

“Hello, World!” print; A variable

declaration

and

assignment; A code snippet

that triggers an error (such as, divide by zero, file not found)

Deliverables:

1. Completed comparison table for two languages

2. Code snippets and/or screenshots

(optional but encouraged)

3. Short written reflection (5 to 6 sentences) answering:

(a) Which language was easier to write and understand?

(b) Which language is better suited for beginners?

(c) What challenges did you face while comparing them?

Document all your findings in a

portfolio.
