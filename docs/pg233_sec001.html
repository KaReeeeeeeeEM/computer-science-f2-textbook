Examples of valid and invalid identifiers in Python:

(i)

student_name = “Bulicheka” # valid identifier

(ii)

_age = 27 # valid (starts with an underscore)

(iii)

Score123 = 100 # valid (contains letters and digits)

(iv)

123score = 100 # Invalid (cannot start with a digit)

(v)

my-name = “Kasupari” # invalid (cannot contain special characters like

‘-’)

Python naming conventions for identifiers

To make Python programs easier to read, developers follow some naming conventions:

(a) Variable names

(i) Use lowercase letters

(ii) Use underscores (_) to separate words (snake_case format)

For example:

student_name = “Mkombozi” # Good naming convention total_marks = 100

The following are other examples of writing variable names:

(i)

myname = “Karubandika”

(ii)

my_name = “ Karubandika ”

(iii) _my_name = “ Karubandika ”

(iv) myName = “ Karubandika ”

(v)

MYNAME = “ Karubandika ”

(vi) myname3 = “ Karubandika ”

(b) Function names

Functions should follow the same snake_case format as variables.

For example:

def calculate_average(): return (50 + 60 + 70) / 3

(c) Private identifiers

If an identifier starts with a single underscore (_), it is intended for internal use only.
