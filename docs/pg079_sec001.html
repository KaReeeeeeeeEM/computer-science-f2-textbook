Student’s Book Form Two

S/No. Type of threat

How to overcome (Security measures)

7.

Cyberbullying and

harassment

Protect yourself online, do not engage with

cyberbullies, document and report abuse, strengthen

digital security, seek support from trusted people,

take legal action, if necessary, promote a positive

online culture.

8.

Spoofing

Implementing secure communication protocols and

verifying the authenticity of digital identities are

crucial defences.

9.

Drive-by attacks

Keep software and systems updated, use secure browsing practices, strengthen endpoint security,

disable unnecessary features, avoid using outdated

and pirated software, monitor network and user activities, educate users on cybersecurity best

practices, and backup critical data regularly.

10.

SQL injection or

XSS attacks

Prioritise secure coding practices and conduct regular

vulnerability assessments to mitigate these risks.

11.

Password attacks

Implement strong authentication, enforce password

policies, and use encryption for data storage. Regularly

update passwords, deploy phishing protection, and

use a password manager. Secure admin accounts, set

up account lockouts and CAPTCHA and establish

an incident response plan. Monitor and respond to threats promptly.

12.

Social engineering and psychological manipulation

Educate and train employees or users, implement

strong identity verification, strengthen email and

communication security, protect sensitive data and

systems, implement strict physical security measures,

monitor and respond to suspicious activity, be

sceptical and trust but verify.
