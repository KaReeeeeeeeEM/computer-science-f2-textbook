Activity 3.1:

Exploring online code editors

Aim: To introduce the use of online

programming editors, including how to

navigate them, identify key areas, and

prepare to write simple code

Materials: Computers or tablets with

Internet access, Browser (Chrome,

Firefox, etc.), List of recommended

online editors such as (Replit-https://

replit.com,Programiz-

https://

programiz.com/python-programming/

online-compiler, JSFiddle https://

jsfiddle.net, Trinket-https://trinket.io )

Instructions:

Step 1: Choose one editor, one after

another and explore

Task options:

(a) Replit / Programiz: Type print("Jambo, Africa!") and run it.

(b) JSFiddle: Select HTML window.

Write a simple message in HTML

like <h1>Hello World</h1>.

(c) Scratch: To create a simple program

in Scratch, go to https://scratch.mit.

edu → click “Create” to start a new project → in the Blocks Palette,

select the “Events” category →

drag the “when green flag clicked”

block into the coding area → then,

go to the “Looks” category → drag

and snap the “say [Hello!] for [2]

seconds” block underneath the

event block. Now, when you click

the green flag, the sprite will say

“Hello!” for 2 second.

Step 2: Identify key areas. Fill in a worksheet or answer in a

notebook about the following questions:

Questions

1. Where do you write your code (or build blocks)?

2. Where do you see the result/output?

3. How do you run or start your program?

4. What was fun or interesting about the editor?

Deliverables:

1. Identify key parts of the editor

(code area, output, run or start)

2. Type or create a simple program

(text-based or block-based)

3. Take a screenshot and complete a short reflection

Document all your findings in a

portfolio.
