Second generation (assembly language)

Assembly language involves a set of symbolic operations called mnemonics.

Mnemonics code is made up of two or three letters, such as LDN, STA, and JPU.

Typical features of the assembly language differ from one computer to another. A program written in assembly language should be translated from the source program to machine code, known as object code. The program required to translate assembly language into machine code is known as an assembler. An example of a program written in assembly language is represented in Table 3.5.
