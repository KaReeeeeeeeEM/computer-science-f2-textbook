Deliverables:

1. Scratch project: A fully functional

reaction game, where the player has to react quickly to a “green

light” and the game measures their reaction time.

(a) Variables: Properly set up

variables for reaction time and game start.

(b) User interface: The game should

display messages like “Wait

for the green light to change!”

and “Green Light!” along with reaction time feedback.

(c) Feedback: The game should

provide a message based on

how fast the player reacts (for

example, ”Great job!” or “Try

again!”).

(d) Reset functionality: The game

should be able to restart after

each round.

2. Project file: The project should be

saved and shared via scratch or

provided as a downloadable file.

3. Reflection/report (optional): A

brief write-up to reflect on how you

created your game, the challenges

you faced, and what you learnt

about programming concepts

(such as variables, events, and

timers).

Activity 3.14:

Integrating micro:bit for Input (using

blocks)

Aim: To build a simple reaction timer

using the micro:bit by capturing and

displaying the time between a “Go!”

signal and a button press.

Materials: Micro:bit device (or

simulator via MakeCode), computer or

tablet with Internet access, USB cable (if

using a physical micro:bit), MakeCode

Editor (online or offline), and notebook

or worksheet (for recording reaction

times and observations)

Instructions:

Step 1: Set up micro:bit

(a) Go to MakeCode for micro:bit and click New Project.

(b) Name the project and click Create to start a new project.

Step 2: Basic setup

(a) Button A: Start the game

(i) Drag the “on button A

pressed” block from the Input

category.

(ii) Under it, use the “show string” block from the Basic

category to show “Starting...”

on the micro:bit’s LED

screen, as shown in Figure

3.19.

Example: on button A pressed

Show string “Starting”
