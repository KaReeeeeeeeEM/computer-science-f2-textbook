Web server

A web server is a computer that stores web-related files. The web servers have high processing power and storage capacity. The main goal of web servers is to provide users with access to information and other resources on the Internet. When you use a web browser to request a particular web page, a web server processes your request and gives you the requested information.

Hyperlink

The hyperlink is a link between two web resources. When clicked, a hyperlink takes

you to another resource on the web. When the mouse pointer passes over a hyperlink,

it (mouse pointer) changes from an arrow to a pointing hand.

Hypertext

Hypertext is a text that contains hyperlinks. The hyperlinks are references to other documents and media on the web server.

Uniform Resource Locator

Another important term in network communication is the Uniform Resource Locator

(URL). URL is a reference to a web resource that specifies its location on a computer

network. The URL considers a zone and an organisation to which the site belongs.

An example of a URL is https://www.tie.go.tz. The URL contains four parts: an

Internet protocol, a domain name, a pathname, and a filename. The domain name is a

text-based representation of an IP address, which is easier to remember. The Domain

Name System server facilitates the resolution of domain name into IP address and can also perform reserve lookups when required. The URL address scheme of the

Web browser has four parts as shown in Figure 1.5:

(a) Specific transfer protocol to be used for transporting the file.

(b) The domain name of the computer on which the file resides.

(c) The pathname of the folder or directory on the computer on which the file resides; and

(d) The name of the file.
