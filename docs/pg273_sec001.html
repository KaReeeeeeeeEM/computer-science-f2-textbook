Unpatched vulnerability

An unpatched vulnerability is a security flaw in

software that has not yet been fixed by a software update or patch. In simple terms, A vulnerability is a weak spot in a system. If the organization hasn’t

released a fix, or users haven’t installed it, it is

unpatched. Hackers can exploit it to attack systems.

VPN

VPN stands for Virtual Private Network. It is a technology that creates a secure, encrypted

connection between your device (computer, phone,

etc.) and the Internet.

Zoom meeting
