Constants and #define Macros

Constants are values that do not change during program execution. There are two main ways to define constants:

(a) Using const keyword

For example,

const float PI = 3.1416; // Value of PI cannot be changed

(b) Using #define Macro

For example

#define MAX_STUDENTS 50 // Defines a constant without using memory

Unlike const, #define is processed before compilation, making it more efficient for fixed values.

Type conversion and type casting

Sometimes, you need to convert one data type into another. There are two types of conversions:

(a) Implicit type conversion (Automatic)

The compiler automatically converts smaller data types into larger ones to prevent

data loss.

int num = 10;

float result = num; // Converts int to float automatically

printf("%f", result); // Output: 10.000000

(b) Explicit type conversion (Type casting)

You can manually convert a data type using type casting.

float num = 5.75;

int result = (int) num; // Converts float to int manually

printf("%d", result); // Output: 5 (decimal part is removed)
