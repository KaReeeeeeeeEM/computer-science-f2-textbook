Using comments

Comments are lines in your code that Python ignores. They are helpful for adding

notes or explanations about what the code is doing. There are two types of comments:

(a) Single-line comments

Use the # symbol to write comments for one line.

For example:

# This is a single-line comment print("Jambo, Tanzania!") # This prints a message

(b) Multi-line comments: You can use triple quotes (‘“or ””) to write comments

that span multiple lines.

For example:

'''

This is a multi-line comment

explaining the purpose of the program.

'''

print("Hello, World!")

Displaying output with print()

The print() function displays information (output) on the screen. It can show text,

numbers, or the result of calculations.

For example:

print("Hello, World!") # Displays: Hello, World!

print(5 + 3) # Displays: 8

Taking user input with input()

The input() function allows you to get input from the user. It pauses the program and waits for the user to type something on the keyboard. The value entered by the user is returned as a string (text).
