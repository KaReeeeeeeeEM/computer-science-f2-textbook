GLOSSARY

ASCII

ASCII, short for American Standard Code for

Information Interchange, is a system used to encode

characters using 7 bits, allowing it to represent 128

different symbols. These symbols include English

letters (both uppercase and lowercase), numbers,

punctuation marks, and special control characters

such as newline and tab. As one of the first character

encoding systems, ASCII remains in use today for

basic programming and plain text files.

Binary system

The binary system is a way of representing numbers

and data using only two digits: 0 and 1. It is the

language of computers, as all digital devices use

binary to store and process information. Each digit in

a binary number is called a bit, and combinations of

bits are used to represent everything from numbers

and letters to images and sounds. Computers use the

binary system because it matches their electronic

structure where a circuit is either on (1) or off (0).

Breach

In computer science and cybersecurity, a breach

(short for security breach) means that someone gained unauthorized access to data, systems,

or networks often resulting in data being stolen,

exposed, or damaged.

CISCO Webex

Cisco Webex is a video conferencing and collaboration platform developed by Cisco. It

allows people to meet, chat, share content, and work

together online similar to Zoom, Google Meet, or

Microsoft Teams
