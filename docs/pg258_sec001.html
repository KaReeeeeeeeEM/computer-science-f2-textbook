(b) Removing elements from a list

You can remove an item from a list using the remove() method or the pop() method

(which also returns the removed item).

Removing an item from a list using remove():

For example

lakes= ["Victoria", Eyasi,"Tanganyika"]

lakes.remove(“Eyasi”)

print(lakes) # Output: ["Victoria", "Tanganyika"]

Removing an item from a list using pop():

lakes= ["Victoria", Eyasi,"Tanganyika"] removed_lake = lakes.pop(1) # Remove and return the item at index 1 print(lakes) # Output: [“Victoria”, "Tanganyika"] print("Removed:", removed_lake) # Output: Removed: Eyasi

Iterating over lists using loops

You can loop through all the elements of a list using a for loop. This allows you to perform actions on each item in the list.

For example:

lakes = ["Victoria", Eyasi,"Tanganyika"] for lake in lakes: print(lake)

Output:

Victoria

Eyasi

Tanganyika
