A C program follows a defined structure with key components necessary for proper execution. The next paragraphs present an overview of the basic structure:

(a) #include preprocessor directive

The #include directive is used to include external libraries in your program. These

libraries provide additional functionality, such as input/output operations.

For example:

#include <stdio.h> // This signifies the standard Input/Output library

(b) main() function

Every C program needs a main() function. This is where the program begins

running. It can give an integer value back to the Operating System (usually 0 to

indicate the program ran successfully).

For example:

int main() {

// Code is written here

return 0;

}

Note: A function in C is a block of code that performs a specific task. It helps break a big program into smaller, reusable parts.

(c) Curly braces {}

Curly braces {} are used to define blocks of code, such as the body of functions and loops. The code written inside these braces will be executed.

Writing and using comments

Comments are used to add explanatory notes in the code. The compiler does not

execute them but helps programmers understand the code better. Types of comments

include:

(a) Single-line comment

A single-line comment begins with //. Everything following // on that line is

considered a comment.
