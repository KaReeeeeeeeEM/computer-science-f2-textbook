Debugging techniques in C

Debugging is the process of finding and fixing errors in your code. Here are some simple ways to debug your program:

(a) Read the error message carefully

The compiler’s error messages are helpful. They often tell you where the error is and what type of error it is.

(b) Use print statements

Add printf() statements to check if variables have the values you expect.

#include <stdio.h> int main() { int a = 5, b = 2; printf("a = %d, b = %d\n", a, b); // Print values of a and b int result = a + b; printf("result = %d\n", result); // Print the result return 0;

}

(c) Use a debugger

Many programming environments have debuggers that let you step through your code line by line to see what is happening.
