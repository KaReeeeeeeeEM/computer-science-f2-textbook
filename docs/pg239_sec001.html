Table 5.5: Logical operators

Python uses logical operators such as and, or, and not to combine or invert conditions,

as illustrated with examples in Table 5.5

Operator Meaning

Example (a = True, b = False) Output

and

Both conditions must be True a and b

False

or

At least one condition is True a or b

True

not

Reverses True/False

not a

False

For example, let:

x = 10 y = 5 print(x > y and y < 3) # False (one condition is False) print(x > y or y < 3) # True (one condition is True) print(not (x > y)) # False (reverses True to False)
