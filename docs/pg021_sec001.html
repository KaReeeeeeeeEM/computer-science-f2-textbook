Search engines

Since the advent of the Internet, people

have been storing and sharing vast

amounts of information online. One major

challenge for users has been locating and

retrieving relevant content quickly. To

address this need, specialized software

was developed, leading to the creation

of search engines.

Meaning of a search engine

A search engine is software used to search

for resources on the Web based on the

keywords you designate to search. It is a

software designed to retrieve information

from the World Wide Web. The search results are generally presented in a list of

results, often referred to as search engine

result pages. Some search engines also

extract data that is available in databases

or open directories. Search engines look through online databases to find

information that users are looking for.

The search results are usually presented

in a list and are commonly called hits.

The information may consist of web

pages, images, and other types of files.

Some of the commonly used search

engines are:

(a) Google (www.google.com)

(b) Yahoo (www.yahoo.com)

(c) Bing (www.bing.com)

(d) MSN (www.msn.com)

Using search engines

A search engine works by using a special

computer program called a spider or crawler. This program visits websites,

reads their content, and follows links from

one page to another. The information it

collects is then indexed and stored in

the search engine’s database. Crawlers

can scan many websites at the same time, gathering both new and updated

information. By collecting and ranking

the large amounts of data quickly, search

engines like Google are able to provide useful and relevant results when people search online.

The order and selection of pages shown in search results are decided by Google’s ranking algorithms
