Using debugging tools

Using debugging tools such as an IDE’s debugger may help in making sure your program looks error-free. Many Integrated Development Environments (IDEs) like

Code::Blocks, Dev-C++, or Visual Studio have built-in debugging tools that allow you to:

(i) Step through your code (line by line).

(ii) Set breakpoints (stop at a certain point in the code).

(iii) Watch variables to see how their values change.
