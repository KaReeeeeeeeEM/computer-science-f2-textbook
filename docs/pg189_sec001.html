Introduction to control flow in C

Control flow is the order in which individual statements are executed in a C program.

Control flow is essential in programming because it allows the program to make

decisions, repeat actions, and react to different situations.

(a) Sequential flow: This is the default behaviour, where the program executes each statement in order, from top to bottom. For example:

int a = 10; int b = 20; int sum = a + b; printf(“Sum is: %d\n”, sum);

In this example, the statements are executed sequentially: first, a and b are assigned values, then the sum is calculated, and finally, the result is printed.

(b) Selection flow: This type of control flow makes decisions based on conditions.

It allows the program to execute different blocks of code based on the result of a condition.

(c) Iterative flow: This type of control flow involves repeating a block of code multiple times. It is commonly used in loops such as for, while, and do-while.

Selection flow

Selection flow involves conditional statements, which are used for decision-making in programming. This process is essential because it allows a program to perform different actions based on specific conditions, enabling more flexible and intelligent behaviour. By using conditional statements, you can make a program that:

(i) Responds to user input,

(ii) Checks if certain conditions are met,

(iii) Executes code based on various scenarios.

For example, you can write a program that asks for the user’s age and tells them

whether they are eligible to vote based on the age input. The selection flow uses many

statements, as described in subsequent paragraphs.
