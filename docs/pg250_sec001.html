The while loop – Repeating based on a condition

A while loop runs as long as a condition is true. It is useful when you do not know in advance how many times the loop should run.

num = 1 # Start at 1

while num <= 5: # Keep looping while num is 5 or less

print(num) # Print the current number

num += 1 # Increase num by 1
