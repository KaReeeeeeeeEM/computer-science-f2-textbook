Table 2.10: Types of cyber threats and their security measures

S/No. Type of threat

How to overcome (Security measures)

1.

Phishing

Always check the sender’s email, avoid clicking on

unknown links, and never share personal details with

untrusted sources.

2.

Malware

Users should install antivirus software, keep systems

updated, avoid suspicious links, and use strong

cybersecurity practices.

3.

Ransomware

Implement strong backups and data recovery,

endpoint protection, and network security. Educate users to prevent phishing, patch software regularly,

and enforce strong authentication and access controls.

Develop an Incident Response Plan, use application

whitelisting, and monitor for ransomware activity.

4.

Business Email

Compromise (BEC)

Employee awareness and training, implement strong

email security measures, strengthen financial and

approval processes, use threat intelligence and

monitoring, implement data protection and access

controls, and establish an incident response plan.

5.

Distributed Denial of Service (DDoS)

Use special tools and security measures to detect

and block these attacks before they cause damage.

Implement a content delivery network (CDN) and

cloud-based DDoS protection services for additional

mitigation. Regularly update security protocols

and monitor network traffic for early detection of

anomalies.

6.

Data breaches

Organisations should focus on employee training,

strong email security, data protection, access

controls, and an incident response plan. Key actions include encrypting sensitive data, updating systems, securing devices, and backing up data. Compliance with security regulations and an effective response to data breaches are also crucial.
