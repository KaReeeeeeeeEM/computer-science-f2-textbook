Waiting for user input

In Python, we can prompt the user for input by displaying a message and waiting for their response. The following example asks the user to press a key before exiting the program:

input("\n\nPress Enter to exit.")

Referring to this code:

(i)

The input() function is used to wait for user input. Unlike Python 2’s raw_

input(), which is now obsolete, Python 3 only uses input().

(ii) The “input()” function in Python is used to pause the program and wait for user input. In Python 3, “input()” replaces the old “raw_input()” function from Python 2, which is now outdated and no longer used.

(iii) The “\n\n” at the beginning adds two blank lines before displaying the prompt, improving readability.

(iv) The program pauses execution until the user presses “Enter,” after which it continues or exits.

This approach ensures that the console window stays open until the user decides to close it. This is useful in applications where closing the window immediately is not desired.
