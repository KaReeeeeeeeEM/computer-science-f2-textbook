For example:

age = 16

has_ID = True if age >= 18 and has_ID: print("You can vote.") else: print("You cannot vote.")

Referring to this code, the person can only vote if they are 18 or older and have an

ID. Again, consider the following:

day = "Sunday" if day == "Saturday" or day == "Sunday": print("It is the weekend!") else: print("It is a weekday.")

Referring to this code, the program prints “It is the weekend!” when it is Saturday or Sunday. Consider the following code as well:

rainy = False if not rainy: print("You do not need an umbrella.")

This code demonstrates that because rainy is set to False, the expression not rainy evaluates to True, which causes the message to be printed.
