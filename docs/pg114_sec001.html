Activity 3.2:

Exploring offline code editors

Aim: To learn how to open and navigate

offline code editors and identify

important areas like the code writing

area, run button, and output area.

Materials: Computers or laptops

with offline code editors (such as, VS

Code, Notepad++, PyCharm, Sublime

Text for Python and Code::Blocks,

Dev-C++, or VS Code for C), pre-

installed

programming

languages

(such as, Python or C), worksheet or

checklist for students to fill in during

the activity, sample code file (can be a

simple “Jambo, Dunia!” program)

Instructions:

Step 1: Choose one editor, one after

another, and explore:

Task options:

For Python:

(a) Open VS Code or PyCharm (or any

installed Python editor).

(b) Create a new file or open an existing

file to write Python code (File >

New or use Ctrl + N).

For C:

(a) Open Code::Blocks, Dev-C++, or

VS Code (if set up for C).

(b) Create a new project or open a new file to write C code.

Step 2: Identify key areas and fill in

a worksheet or answer in a

notebook:

For Python

(a) Code writing area: Where the code is written.

(b) Output area/terminal: Where the

result appears after running the

code.

(c) Run button/shortcut: Usually, a

green triangle button or F5 is used

to execute.

For C

(a) Code writing area: Where the C program is written.

(b) Output/console area: Where you see the result of the program after running it.

(c) Run button/shortcut: Usually, a green play button or F9 is used to run the program.

Step 3: Write and run simple programs

(write and run a simple Jambo,

Dunia! program in Python and

C.

For Python

(a) Open the editor and type the following Python code:

print("Tanzania, my beautiful country!")
