Operator precedence in C

Operator precedence defines how terms in an expression are grouped and evaluated.

Some operators take priority over others; for instance, multiplication has a higher precedence than addition.

For example, in the expression x = 8 + 4 * 3;, x is assigned the value 20, not 36.

This happens because multiplication (*) is performed before addition (+), so 4 * 3 is calculated first, resulting in 12, which is then added to 8.

Operators with the highest precedence are listed at the top of the table, while those

with the lowest precedence are at the bottom. In an expression, operators with higher

precedence are evaluated before those with lower precedence as shown in Table 4.6.
