Exception handling

Exception handling is how a program

deals with unexpected problems while

it is running. These problems, called

exceptions, can stop the program from

working correctly and might even cause it to crash. By using exception handling, a program can deal with such problems more safely and keep running smoothly.

Exceptions can happen for many reasons,

like when a user enters the wrong input, a

mistake is made in the code, the computer

runs out of memory, there is a problem with the Internet connection, or a file is

missing. To handle these problems, many

programming languages include special tools like try, catch, except, and finally.

These help the program check for errors

and take action when something goes

wrong. In some cases, exception handling

can also use deeper system features, like

hardware alerts or messages from the

operating system.

Differences between exception handling

and error handling

While both techniques help maintain smooth program execution, exception

handling focuses on managing recoverable

issues that may arise during runtime. In

contrast, error handling typically deals

with more severe or unexpected problems

that may require corrective actions or

program termination.

Common exceptions

1. Division by zero: Occurs when a

program attempts to divide a number

by zero.

2. File not found: Happens when a program tries to open a non-existent file.

3. Index out of range: Occurs when

accessing an element in a list or array

using an invalid index.

4. Value error: Arises when a function

receives an argument of the correct

type but with an inappropriate value.
