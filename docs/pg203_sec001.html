Function arguments

If a function requires arguments, it must declare variables to hold the values of those

arguments. These variables are known as the formal parameters of the function.

Formal parameters function like other local variables within the function, being

created when the function is entered and destroyed when the function exits. When calling a function, arguments can be passed in two ways:

(i) Call by value: In this method, the value of an argument is copied into the function’s formal parameter. As a result, any modifications made to the parameter within the function do not affect the original argument.

(ii) Call by reference: This method passes the address of an argument to the function.

The function uses this address to access and modify the original value. As a result,

any changes made within the function directly affect the argument.

Call by value

In the call-by-value method, the argument’s value is passed to the function by copying

it into the parameter. Therefore, changes inside the function do not alter the original

value. By default, C uses this method, which means functions cannot directly modify

the values of passed arguments.
