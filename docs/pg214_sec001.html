Working with text files

Working with text files in C involves performing file operations like creating,

reading, writing, and closing files using the standard I/O library (stdio.h). Text files store data as plain characters, and C provides a simple set of functions for manipulating them.

Writing to a file using fprintf( ): fprintf() is a function from the C standard I/O library (<stdio.h>) that allows you to write formatted text to a file, just like printf() writes to the console.

#include <stdio.h>

int main() {

FILE *file = fopen("myfile.txt", "w"); // open file in write mode

if (file == NULL) {

printf(“Error in opening a file!\n”);

return 1;

}

fprintf(file, "Hello, this is a file handling example!\n");

fprintf(file, "File handling makes data storage easy.\n”);

fclose(file); // Close the file

// Confirmation message printf("Data written to file successfully.\n"); return 0;

}
