Domain Name System

The Domain Name System (DNS) works like an Internet directory, allowing us to

use familiar website names like tie.go.tz, google.com, or facebook.com instead of

memorizing long numerical IP addresses such as 192.168.1.1. DNS translates these

domain names into the correct IP addresses so that computers can locate and load

the appropriate websites. This makes accessing websites easier, faster, and more

convenient.

Figure 1.17 illustrates this DNS resolution process. When a user enters "google.

com" into their browser, the request is sent to a DNS server. The server looks up the

domain name and returns the corresponding IP address, in this case, 74.125.68.102.

The user's request is then directed to the web server associated with that IP address,

enabling access to the Google website. The arrows in the figure represent the flow of

information from the user to the DNS server and then to the destination web server.
