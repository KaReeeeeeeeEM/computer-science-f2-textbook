grade:

(a) 90-100: A

Exercise 4.5

1. The following program checks whether a number is positive or negative, but

there’s an error. Identify and fix the issue.

#include <stdio.h>

int main() {

int number = -5;

if (number > 0) printf(“Positive\n”); else printf(“Negative\n”); return 0;

}

2. Write a C program that checks if a given number is even or odd using an if- else statement.

3. Write a C program that reads a student’s marks and prints their grade using if-else statements. The grading scheme for the score is as follows:

A for marks >= 85

B for marks >= 70

C for marks >= 50

D for marks < 50

4. Write a C program that checks if a number entered by a user is between 10 and 20 (inclusive) using if-else statements. If it is, print “In range”; otherwise, print “Out of range”.

5. Write a C program that checks if a number is greater than zero and less than

100. If it is, print “Valid number”; otherwise, print “Invalid number”.
