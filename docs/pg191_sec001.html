(c) else-if Ladder

The else-if ladder allows checking multiple conditions sequentially. It is useful when

there are several possible outcomes based on different conditions.

Syntax:

if (condition1) {

// Code for condition1

} else if (condition2) {

// Code for condition2

} else {

// Code if no conditions are true

}

For example:

#include <stdio.h> int main() { int num = 25; if (num > 30) { printf(“Greater than 30\n”);

} else if (num > 20) { printf(“Greater than 20 but less than or equal to 30\n”);

} else { printf(“20 or less\n”);

} return 0;

}

Referring to this example, this program checks if the num is greater than 30. If not, it checks if the num is greater than 20. If both conditions are false, the else block executes.
