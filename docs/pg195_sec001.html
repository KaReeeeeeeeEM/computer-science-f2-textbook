(b) for loop

A “for” loop is a control structure used for efficiently repeating a block of code a specific number of times.

Syntax:

for (initialisation; condition; increment)

{ statement(s);

}

The flow of control in a “for” loop is as follows:

(i) Initialisation: This step runs once before the loop starts. It is used to declare and set the loop control variable. This part is optional but must be followed by a semicolon.

(ii) Condition check: Before each iteration, the condition is evaluated. If it is true, the loop body executes. If false, the loop stops and the control moves to the next statement after the loop.

(iii) Increment/update: After executing the loop body, the control moves to the increment step, which updates the loop control variable. The condition is then rechecked, and the process repeats.

The loop continues to execute as long as the condition remains true. Once the condition

becomes false, the loop stops. Figure 4.4 shows the structure of a for loop.
