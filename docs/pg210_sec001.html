Introduction to strings and string handling

A string in C is an array of characters. Strings are used to store text.

Declaring a string

A string is declared as a character array. The array size must be big enough to hold the characters plus the null terminator \0.

Initialising a string

You can initialise a string directly when you declare it.

char name[] = "John"; // A string that stores “John”

String handling functions in C

When working with strings in C, there are several important functions that help

with input, output, and processing of text data. The following sections provide brief

descriptions and demonstrations of three common string functions: gets(), puts(),

and strlen().

(a) gets(): Reads a line of text from the user.

Note: Using gets() in real programs is normally avoided, as it can lead to a buffer

overflow.

char name[20];

gets(name); // Read a string from the user

Alternatively, for real programs, fgets can be used:

#include <stdio.h> int main() {

char name[20];//Declare a string with a maximum size of 19 characters

// Use fgets to read a string from user input printf("Enter your name: "); fgets(name, sizeof(name), stdin); // Read up to 19 characters printf("Your name is: %s\n", name); return 0;

}
