Example of reading a file

file = open("example.txt", "r") # Open the file in read mode

content = file.read() # Read the file content print(content) # Display content

file.close() # Close the file

Writing to files

The write() method allows new content to be written in a file.

Example: Writing to a file (overwriting)

file = open("example.txt", "w") # Open in write mode

file.write("Hello, this is a new file.") # Write content

file.close() # Close the file

Note: Using “w” mode erases any existing content before writing new data.

Example: Appending to a file

file = open("example.txt", “a”) # Open in append mode

file.write(“\nThis is an additional line.”) # Add new content

file.close() # Close the file

Note: Appending (“a”) does not delete existing content but adds new text at the end.

Closing files properly (close())

After working with a file, it is important to close it to free up system resources. The method file.close() is used to close a file. However, a better way to handle files is to use the with statement, which automatically closes the file.

For example:

with open("example.txt", "r") as file:

content = file.read() print(content)

# No need to call file.close() – it is closed automatically
