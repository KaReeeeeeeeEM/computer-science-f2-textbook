Activity 4.5:

Installation of Code::Blocks as an IDE

Code::Blocks is a free C/C++ IDE that comes with built-in support for

MinGW-w64. The following are steps to install Code::Blocks:

Step 1: Download Code::Blocks

(a) Visit the Code::Blocks from the

official website, https://www.

codeblocks.org/downloads/

(b) Under “Download the binary”

release, choose the version with

MinGW included.

Step 2: Install Code::Blocks

Step 3: Verify MinGW Compiler

Setup

(a) Open Code::Blocks.code

(b) Go to Settings → Compiler.

(c) Ensure the Selected Compiler is set to GNU GCC Compiler.

(d) Click Auto-detect to check if

MinGW is installed correctly.

(e) Alternatively, you can manually set the compiler path to:

C:\Program Files\CodeBlocks\

MinGW

(f) Click OK to save settings.

Step 4: Create and run a C program

(a) Open Code::Blocks and go to

File → New → Project.

(b) Choose “Console Application”

→ C Language → Click Next.

(c) Enter a project name and save the location. After saving you should see an interface like in
