Reading from and writing to files in C

C provides file-handling functions that allow programs to open, read, write, and close files. Table 4.7 lists the basic functions used for these file operations.

Table 4.7: Basic file handling functions

Function

Purpose

fopen()

Opens a file

fclose()

Closes a file

fprintf()

Writes data to a file

fscanf()

Reads data from a file

Opening a file (fopen)

Before reading or writing, you must open a file using the fopen() function. A

description of file modes is presented in Table 4.8.

FILE *file; file = fopen(“myfile.txt”, “w”); // open file in write mode
