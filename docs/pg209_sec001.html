Two-dimensional arrays (matrices)

A two-dimensional (2D) array is like a table or a matrix, where you have rows and columns. It can store multiple rows and columns of data.

Declaring a two-dimensional array

To declare a 2D array, you need to specify the number of rows and columns.

int matrix[3][3]; // A 3x3 matrix (3 rows and 3 columns)

Initialising a two-dimensional array

You can initialise a 2D array with values like this:

int matrix[2][2] = {{1, 2}, {3, 4}}; // 2x2 matrix

Accessing elements of a two-dimensional array

To access elements, you need to use two indices: one for the row and one for the column.

printf(“%d”,matrix[1][1]);//Prints the element at row 1, column 1 (which is 4)

matrix[0][0]=10;//Change the element in row 0, column 0 to 10

#include <stdio.h> int main() {

int matrix[2][2] = {{1, 2}, {3, 4}}; // Declare and initialise a 2x2 matrix

// Accessing and printing elements printf("Element at row 1, column 1: %d\n", matrix[0][0]); printf("Element at row 2, column 2: %d\n", matrix[1][1]);

// Changing an element matrix[1][0] = 100; // Change element at row 2, column 1 to 100

printf("Changed element at row 2, column 1: %d\n", matrix[1][0]);

return 0;

}
