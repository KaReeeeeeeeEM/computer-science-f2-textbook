Project Development of a simple calculator in C

Aim: To develop a basic calculator using C programming language that can perform

arithmetic operations (addition, subtraction, multiplication, and division).

Project requirements:

1. The program should prompt the user to enter any two numbers.

2. The user should select an operation (+, -, *, /).

3. The program should compute and display the result.

4. The program should check for division by zero and display an error message

if attempted.
