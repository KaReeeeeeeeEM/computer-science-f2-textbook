Step 1: Download MinGW-w64

(a) Go to the official MinGW-w64 website: https://www. mingw-w64.org/ or from any source such as https:// sourceforge.net/projects/ mingw-w64/.

(b) Download the installer (for

example, mingw-w64-install.

exe).

Step 2: Install MinGW and follow the setup instructions.

Step 3: Set up “Environment

Variables”

(a) Open the “Start menu” and search for “Environment

Variables”.

(b) Click

“Edit”

the

system

environment variables.

(c) In the “System Properties

window”, click “Environment

Variables” which is in the

Advanced tab (for Windows

11).

(d) Under “System Variables”, find

“Path” and click “Edit”.

(e) Click “New” and add the path

to MinGW’s bin directory (such

as, C:\mingw-w64\mingw64\

bin).

(f) Click “OK” to save changes.

Step 4: Verify Installation

(a) Open Command Prompt (cmd).

(b) Type: gcc –version

Note: The GCC version will be displayed if the installation is

successful. Now compile C programs with the following command: gcc program.c -o program.exe
