Case study 2.2: Equifax data breach

(2017)

(i)

Attack type: Data breach

(ii)

Target: Equifax (one of the

largest credit reporting agencies)

(iii) Impact: Personal data (including social security numbers) of 147 million people were stolen.

(iv) Cause:

An

unpatched

vulnerability in Apache Struts

(a web application framework).

(v)

Lesson: Regular security

updates and better vulnerability

management are crucial.

Case study 2.3: SolarWinds supply

chain attack (2020-2021)

(i)

Attack type: Supply chain attack

(ii)

Target: SolarWinds software

(used by governments and large corporations)

(iii) Impact: Hackers inserted

malware into a software update,

compromising U.S. government

agencies, Microsoft, and

cybersecurity firms.

(iv) Cause: Nation-state hackers

compromised SolarWinds’

software update process.

(v)

Lesson: Even trusted software

updates can be exploited; organisations must verify

security at every stage.

Case study 2.4: Yahoo data breaches

(2013 and 2014)

(i)

Attack type: Data breach

(ii) Target: Yahoo (a major tech company)

(iii) Impact: 3 billion accounts were

compromised, leaking names,

emails, passwords, and phone

numbers.

(iv) Cause: Weak security measures and failure to detect the breach quickly.

(v)

Lesson: Strong encryption and

early detection systems are

essential for data protection.

Case study 2.5: Stuxnet worm (2010)

(i)

Attack type: Cyber warfare

(malware)

(ii) Target: Iran’s nuclear facilities

(iii) Impact: Damaged centrifuges

used for uranium enrichment, setting back Iran’s nuclear

program.

(iv) Cause: Highly sophisticated

malware designed to target

industrial control systems.

(v) Lesson: Cyberattacks can have

serious real-world consequences

on critical national security and infrastructure.
