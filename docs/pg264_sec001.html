Python libraries (basic modules)

Understanding Python libraries and modules

(i) Python libraries are collections of pre-written code that provide functions and tools to make programming easier.

(ii) Modules are individual files within a library that contain related functions, variables, and classes.

(iii)You can import these modules into your program to use the functions they provide without writing the code yourself.

Example:

(i) The math library contains functions for mathematical operations.

(ii) The random library provides functions for generating random numbers.

Why use libraries and modules?

(i) Saves time: Instead of coding everything from scratch, you can use libraries to handle common tasks.

(ii) Boosts productivity: Libraries let you access advanced functionality quickly and easily.

(iii) Improves code quality: Libraries are often tested and optimised by experienced developers.
