Arrays and strings

One-dimensional arrays

An array is a single variable that holds a collection of values of the same data type.

A one-dimensional array functions like a list, where each value can be accessed

using its index.

Declaring a one-dimensional array

To declare an array, you specify the data type, followed by the name of the array, and the number of elements (size) it will hold.

For example:

int numbers[5]; // An array of 5 integers

Initialising a one-dimensional array

You can also initialise an array when you declare it. Here is how you can give the array initial values:

int numbers[5] = {10, 20, 30, 40, 50};//array initialised with values

Accessing elements of a one-dimensional array

To access or change an element in the array, use the index number (starting from 0).

printf(“%d", numbers[0]); // Prints the first element, which is 10

numbers[2] = 100; // Change the third element to 100
