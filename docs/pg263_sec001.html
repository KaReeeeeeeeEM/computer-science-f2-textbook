Error handling in Python

Errors can occur while running a program, causing it to stop unexpectedly. Python provides error-handling techniques to manage and fix these issues without stopping the program.

Types of errors in Python

Syntax errors – Occur when the code is written incorrectly. print(“Hello” # Missing closing parenthesis

How to fix: Ensure proper syntax.

Runtime errors (exceptions) – Occur while the program is running, such as division

by zero or accessing a non-existent file. num=5/0 # Division by zero error

TypeError (Incompatible data types)

This happens when you try to mix different types (for example, adding a number and a string).

For example, the following code can cause TypeError:

age = input("Enter your age: ") # input() returns a string print("Next year you will be: " + (age + 1)) # TypeError: Cannot add str and int

To solve this error, you have to convert the input data type to an integer data type using int().
