File handling basics in Python

Introduction to file handling in Python

File handling allows a program to read, write, and manage data stored in files. Python

provides built-in functions to work with files, making it easy to store and retrieve information. The key functions used for file handling are:

(i) open() – Opens a file.

(ii) read() – Reads content from a file.

(iii) write() – Writes content to a file.

(iv) append() – Adds content to an existing file.

(v) close() – Closes the file after use.

Opening and reading files (open(), read())

To work with a file, you must first open it using the open() function. The syntax used to open a file in Python is: file = open(“filename.txt”, “mode””, where:

(a) “r” → Read mode (default)

(b) “w” → Write mode (creates a new file if it doesn’t exist)

(c) “a” → Append mode (adds content to an existing file)

(d) “r+” → Read and write mode
