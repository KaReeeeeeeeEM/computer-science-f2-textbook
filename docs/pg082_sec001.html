How to protect a password

(i) Keep your password private and

never share it with anyone, even

friends or family.

(ii) Never send your password through

email.

(iii) Store and generate secure passwords

with a trusted password manager

instead of writing them down.

(iv) Do not save your password on a computer whenever it prompts you to do so.

Using a password manager

A password manager is a special tool

that helps you securely store and manage

all your passwords. Instead of trying to

remember many different passwords,

you only need to remember one strong

master password to access your password

manager. It can create strong, unique

passwords for each of your accounts and

automatically fill them in when you need

to log in. This helps keep your accounts

safe from hackers and prevents you from

using weak or repeated passwords. Using

a password manager makes it easier to

stay secure online without worrying

about forgetting your passwords. Some

examples of free password managers include Bitwarden, LastPass, and

KeePass.

Procedures for using a password manager

(i)

Select a reliable password manager

such as Bitwarden, LastPass, or

KeePass.

(ii) Install the password manager from the official website or app store on your computer or mobile device.

(iii) Set up a strong master password,

which will be the only password

you need to remember.

(iv) Manually add your existing

passwords or allow the password

manager to save them when you

log in to websites.
