Authentication

Authentication is the process of confirming that a person (or system) is truly who they

claim to be before allowing access to sensitive systems, data, or accounts. It serves as a security checkpoint where credentials or identity proofs must be presented and verified. In simple terms, it answers the question: Are you really who you say you are? Common authentication methods include:

(i) Username and password: This is a traditional method in which users enter a secret combination known only to them.

(ii) Biometrics: Uses unique physical characteristics like fingerprints or facial

features for identity confirmation.

(iii) Two-Factor Authentication (2FA): Adds an extra layer by requiring not only a password but also a second verification method, like a code sent to a phone.
