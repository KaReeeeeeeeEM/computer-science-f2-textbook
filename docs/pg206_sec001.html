Void functions and return statement

A void function is a function that does not return any value. It has a void return type, meaning it does not return any value.

Example

void printText() { // void function, no return value

printf(“Hello, World!\n”);

}

// Calling the function

printText(); // Output: Hello, World!

The return statement is used to exit a function and, optionally, return a value.

Example

void showText() { printf(“Exiting function.\n”); return; // Just exits the function

} showText(); // Output: Exiting function.
