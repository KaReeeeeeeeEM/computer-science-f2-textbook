Moodle

Moodle stands for Modular Object-Oriented

Dynamic Learning Environment. It is a free, open-

source learning management system (LMS) used

to create and manage online courses. Alternatively,

Moodle is a platform that lets teachers create digital

classrooms where students can: Access notes,

assignments, and quizzes; Submit homework; Join

discussions; and Track grades and feedback
