Const variables

In C, const is used to create variables whose values cannot be changed after they

are set. Once you give a const variable a value, you cannot modify it later in the

program. Therefore,

(i) When you declare a const variable, you must give it a value at the time of declaration.

(ii) After that, the value is locked in and cannot be changed.

For example:

const int x = 10; // Correct: 'x' is set to 10 and cannot be changed

Now, trying to change x later in the program will result in an error:

x = 20; // Error: cannot change the value of a const variable

It will give an error because x was set as a constant, meaning its value is locked as

10 and cannot be changed to 20. The reasons for using const variables are that:

(i) It helps prevent accidental changes to important values in your program.

(ii) It is useful for values that should never change after they are set, like constants

(such as, the value of Pi or the maximum allowed score).

So, a “const” variable is like a “locked” value that you set once and cannot alter.

(c) Updating a variable

You can change the value of a variable after declaration.

age = 20; // Changes the value of 'age' to 20

This means that a variable’s value can be changed after it has been declared.

For example:

int age = 15; // Declare a variable ‘age’ and set it to 15 age = 20; // Change the value of ‘age’ to 20

From this example, here is what happens step by step:

(i) int age = 15; → The variable age is created and given the value 15.

(ii) age = 20; → The value of age is updated from 15 to 20.

This is only possible for normal (non-const) variables. If the variable was declared with const, like const int age = 15; then trying to change it (age = 20;) would cause an error.
